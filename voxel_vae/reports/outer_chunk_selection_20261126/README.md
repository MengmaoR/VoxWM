# 外围 16³ 选块覆盖统计

对两个类别包的 200,000 个普通 48³ 快照合并统计。100,000 个 Static 快照按稀有度选块，100,000 个 Dynamic 快照来自 20,000 条五帧链。每帧保留中心，再从其他 26 个位置选块。D4 anchor 未计入普通样本。

全局频数是两个包、所有原划分中每个 canonical token 的体素出现次数。每块的每种 ID 在排序数组中列一次。先比较完整的全局频数升序数组，再比较完整的块内频数降序数组，最后比较完整的 canonical ID 降序数组。块内同全局频数的条目先按本块次数降序，再按 ID 降序对齐。采用标准字典序，严格前缀较短者在前。三层均相同按存储轴顺序的空间块编号从小到大取。

Dynamic 在五个已保存的状态之间做四次相邻比较，同一块至少一个 combined token 改变即计一次。变化次数降序优先，其次按当前帧的稀有度。同一帧的 Top-4、Top-6 均取自一次 Top-8 排序。

| 每帧选择 | 输入块总数 | Static ID | Dynamic ID | 合并后 ID | 未选中的词表 ID | 找回仅在外围的 245 种 |
|---|---:|---:|---:|---:|---:|---:|
| 中心 + 0 | 200,000 | 1,176 | 1,053 | 1,333 | 247 | 0 |
| 中心 + 4 | 1,000,000 | 1,407 | 1,372 | 1,577 | 3 | 244 |
| 中心 + 6 | 1,400,000 | 1,407 | 1,381 | 1,578 | 2 | 245 |
| 中心 + 8 | 1,800,000 | 1,407 | 1,394 | 1,578 | 2 | 245 |

完整 48³ 内实际出现了 1,578 种。词表中的 ID 1115（mcl_ocean:brain_coral_fan, param2=0）和 1161（mcl_ocean:kelp_dirt, param2=55）在这些快照中出现 0 次。Top-4 额外遗漏 ID 6（mcl_amethyst:large_amethyst_bud, param2=1），在 Dynamic 的 3 个快照中各出现 1 次。

| 类别 | 至少一次并列的帧数 | 并列组数 | 并列块对数 | Top-4 跨边界帧数 | Top-6 跨边界帧数 | Top-8 跨边界帧数 |
|---|---:|---:|---:|---:|---:|---:|
| Static | 55,141 | 63,381 | 1,740,427 | 436 | 625 | 719 |
| Dynamic | 71,785 | 83,202 | 2,100,852 | 466 | 735 | 995 |

在每帧 26 个外围候选内，动态优先级（适用时）、全局频数数组和块内次数数组都相同即计并列。一个包含 m 块的并列组计 m(m−1)/2 对。跨边界表示第 K 与 K+1 名属于同一并列组。此次所有并列对在继续比较 ID 后仍然相同，空间位置打破这些并列不会改变该帧选入的 token 种类及次数。
