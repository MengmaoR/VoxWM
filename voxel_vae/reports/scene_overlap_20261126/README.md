# 48³ 场景的世界坐标交叠

数据为两个类别包共 200,000 个普通快照，合并所有历史划分与 Clip。每个 Static 快照算一个场景，Dynamic 按采集链分组，逐条核对五帧的 seed、类别和区域中心相同。D4 anchor 单独存放，不计入普通快照。

以整数世界坐标（东、北、上）记录中心体素，取区域起点加 (24,24,24)。同 seed 的两个场景，若三个轴的中心绝对距离均小于 48，则共有体素数为 (48−dx)(48−dy)(48−dz)。恰好相距 48 为贴边。以下数值衡量空间位置的复用。

| 比较对象 | 同 seed 可比场景对 | 48³ 重叠对 | 同中心对 | 中心 16³ 重叠对 | 涉及场景 | 共有体素数（逐对求和） |
|---|---:|---:|---:|---:|---:|---:|
| Static 内部 | 131,992 | 23 | 0 | 1 | 46 | 685,824 |
| Dynamic 跨链 | 5,306 | 0 | 0 | 0 | 0 | 0 |
| Static × Dynamic | 9,388 | 1 | 0 | 0 | 2 | 39,936 |

Static 的 100,000 个场景有 42,167 个 seed。重叠涉及 46 个场景和 23 个 seed。每对相交 1,024–89,856 个体素。
Dynamic 的 20,000 条链有 16,460 个 seed。每链 5 帧在相同位置记录了不同时间状态，故链内共有 200,000 对空间完全重合的帧。
所有跨场景重叠对均在同一原始 Clip 内。
