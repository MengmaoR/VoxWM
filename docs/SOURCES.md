# VoxEvolve — sources

VoxEvolve is a proposed research direction. The goal animation is a procedural concept illustration, adapted with permission from the owner's original VoxEvolve website.

The recorded Viewer shows engine ground truth and reproduced PERSIST-S / PERSIST-XL rollouts: A 580, B 577, C 469 frames. PERSIST predictions use the recorded GT camera. The published comparison files contain the original plotted values. These are baseline results, not VoxEvolve model results.

The PERSIST method image (`assets/persist-method.png`) is reproduced unchanged from Samuel Garcin, Thomas Walker et al., *Beyond Pixel Histories: World Models with Persistent 3D State* (2026). Source: https://francelico.github.io/persist.github.io/static/images/method.png ; project: https://francelico.github.io/persist.github.io/ ; license: https://creativecommons.org/licenses/by-sa/4.0/

The RGB illustration embedded in `assets/voxel-to-pixel.svg` was AI-generated for the proposed renderer schematic. It is not a trained-model output.
